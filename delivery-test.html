Each vector uses a different --inspect port, so whichever port ends up listening tells us exactly which delivery method survived the browser's URI encoding.

Before testing: close Antigravity completely (single-instance lock makes a second launch exit immediately). Test one vector at a time, close the app between each.

  2. Link with HTML-entity quotes → port 9242

  3. JS navigation (location.href) → port 9243
  4. window.open → port 9244
  5. Hidden iframe (no click) → port 9245
  6. Meta refresh → port 9246

curl.exe http://127.0.0.1:<PORT>/json/version
